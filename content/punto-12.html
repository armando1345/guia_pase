Medir permite dejar de depender únicamente de opiniones.

Sin medición, una reunión puede terminar así:

“A mí me gusta más el anuncio A.”
“Pues a mí el B.”
“Creo que este color funciona mejor.”
“Yo prefiero este titular.”

Con medición aparece una pregunta mejor:

“¿Cuál funcionó mejor?”

El ciclo debería ser:

Hipótesis → publicidad → medición → aprendizaje → nueva prueba.

Y volver a empezar.

Los tests A/B

Una de las formas más sencillas de aplicar esta lógica son los tests A/B.

Se crean dos versiones de una publicidad.

Todo se mantiene igual salvo una variable:

A: un titular.

B: otro titular.

Después se compara cuál consigue mejor el resultado previamente definido.

También puede probarse:

• una imagen;

• una promesa;

• una prueba;

• un formato;

• una sector de una página web;

• un formulario.

La clave es no cambiar cinco cosas simultáneamente, porque después resulta difícil saber qué produjo la diferencia.

Medir según el objetivo

No todas las piezas deberían medirse igual.

Si es activación

Interesan variables como:

• clics;

• QR escaneados;

• registros;

• formularios completados;

• asistencia;

• costo por resultado, cuando exista inversión publicitaria.

Si es construcción de marca

Interesan otras:

• reconocimiento;

• recuerdo;

• conocimiento del PASE;

• asociaciones;

• identificación de activos visuales;

• consideración o intención de utilizar servicios.

Preguntas por responder

Antes de lanzar cualquier campaña responder:

1. ¿Qué queremos conseguir?

2. ¿Qué variable nos dirá si lo conseguimos?

3. ¿Qué podemos comparar o poner a prueba?

4. ¿Qué aprenderemos para la próxima campaña?
